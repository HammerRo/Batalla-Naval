Coloca aquí las 2 imágenes de portada:

1) login_cover.jpg (o .png)
   - Se usa en la pantalla de Login.
2) app_cover.jpg (o .png)
   - Se usa en el Menú principal tras iniciar sesión (invitado o usuario).

Recomendaciones de tamaño:
- 16:9 recomendado: 1920x1080px (Full HD)
- Alta resolución opcional: 2560x1440px o 3840x2160px
- Mínimo aceptable: 1280x720px

Notas:
- Se muestran en pantalla completa con object-fit: cover (puede recortar bordes).
- Deja márgenes de seguridad (safe area) en los lados para que no se recorten elementos importantes.
- Formato: JPG optimizado (calidad 75-85) o PNG si necesitas transparencia.
